# ADR-0002：SQLite 是运行状态的权威来源

- 状态：Accepted
- 日期：2026-07-15

## 背景

Run、Task、Attempt 状态频繁变化，并需要暂停、取消、崩溃恢复和历史查询。依赖大型 JSON 文件会导致并发写入、原子性和恢复困难。

## 决策

SQLite 保存所有运行状态；仓库配置 JSON 和输出 Markdown/JSON 只作为可迁移镜像与导出。

## 后果

- 所有业务写入必须通过 Repository 和事务；
- 需要 Migration、备份和只读恢复模式；
- 前端不能直接访问数据库；
- 导出文件失败不会否定已经成功的模型请求，但必须显示导出异常。
