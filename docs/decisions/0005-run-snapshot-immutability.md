# ADR-0005：Run 快照创建后不可变

- 状态：Accepted
- 日期：2026-07-15

## 背景

运行过程中用户可能修改项目提示词、模型、上下文或 API 路由。若这些修改影响正在执行的 Task，同一 Run 将无法复现，也难以解释不同文件结果差异。

## 决策

创建 Run 时冻结文件清单、内容哈希、提示词、模型、上下文版本、API 路由、重试策略、应用版本和 Schema 版本。运行中修改仅影响未来 Run。

## 后果

- Run 可以审计和复现；
- 重新分析必须新建 Run 或 Task 版本；
- 快照占用一定数据库空间，但不默认保存完整源码内容。
